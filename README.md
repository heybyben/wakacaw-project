# wkcwprjct. 🚀

A premium, minimalist personal portfolio designed for Android developers and tech enthusiasts. Built with a focus on fluid interactions, cosmic aesthetics, and automated content management.

## ✨ Key Features

- **Cosmic Parallax Experience**: Interactive planetary background that responds to your mouse movement.
- **Custom Fluid Cursor**: Dual-layer smart cursor with reactive hover states for interactive elements.
- **Auto-Detected Blog System**: Fully automated post discovery using Vite's glob import. Just add a `.md` file to `src/posts/` and it's live!
- **Premium Emerald Theme**: A carefully curated color palette designed for high-end digital aesthetics.
- **Glassmorphism UI**: Modern transparent interfaces with subtle blurs and pendar glows.
- **Responsive & Lightweight**: Optimized for both mobile and desktop without sacrificing performance.

## 🛠️ Technology Stack

- **Core**: HTML5, Vanilla JavaScript (ES6+)
- **Styling**: Modern CSS3 (Variables, Grid, Flexbox)
- **Engine**: [Vite](https://vitejs.dev/)
- **Content**: Markdown (Parsed with Marked.js)
- **Animation**: CSS Transitions & Keyframes

## 🚀 Getting Started

To get this universe running on your local machine:

1. **Clone the repository**
2. **Install dependencies**
   ```bash
   npm install
   ```
3. **Run the development server**
   ```bash
   npm run dev
   ```
4. **Build for production**
   ```bash
   npm run build
   ```

## 📝 How to Post an Update

The blog system is fully automated. To add a new project update:

1. Place your image in `public/images/`.
2. Create a new `.md` file in `src/posts/`.
3. Use the following frontmatter:
   ```markdown
   ---
   title: Your Project Title
   date: Month DD, YYYY
   tags: Tag1, Tag2
   image: /images/your-image.png
   excerpt: A short summary of the update.
   ---
   ```
